# 🖥️ System Resource Monitor

실시간 시스템 리소스 모니터링 대시보드입니다. 현대적이고 직관적인 UI로 시스템의 모든 주요 리소스를 실시간으로 모니터링하고 PDF로 내보낼 수 있습니다.

## ✨ 주요 기능

### 📊 실시간 모니터링
- **CPU**: 사용률, 온도, 속도, 코어 정보
- **메모리**: 사용량, 사용률, 스왑 메모리
- **디스크**: 파일시스템별 사용량, 온도
- **네트워크**: 실시간 업로드/다운로드 트래픽
- **GPU**: 모델, VRAM, 온도 (지원되는 경우)
- **프로세스**: 실행 중인 프로세스 및 리소스 사용량
- **배터리**: 충전 상태, 잔량 (노트북의 경우)
- **시스템 정보**: 호스트명, 플랫폼, 가동 시간

### 📈 시각화
- Chart.js를 활용한 실시간 그래프
- 직관적인 진행률 바 및 게이지
- 색상 코딩된 경고 시스템 (높은 사용률 시 빨간색)

### 📄 PDF 출력
- 현재 모니터링 상태를 PDF로 내보내기
- 보고서 생성에 적합

### 🎨 현대적인 UI
- 다크 테마 디자인
- 네온 색상의 그라데이션
- 반응형 레이아웃 (모바일 지원)
- 부드러운 애니메이션 및 호버 효과

## 🚀 기술 스택

### Backend
- **Node.js**: 서버 런타임
- **Express**: 웹 서버 프레임워크
- **WebSocket (ws)**: 실시간 양방향 통신
- **systeminformation**: 시스템 정보 수집

### Frontend
- **HTML5**: 구조
- **CSS3**: 스타일링 (그라데이션, 애니메이션)
- **JavaScript (ES6+)**: 로직
- **Chart.js**: 실시간 차트
- **jsPDF**: PDF 생성
- **html2canvas**: 화면 캡처

## 📦 설치 방법

### 1. 저장소 클론 또는 다운로드

```bash
git clone <repository-url>
cd solideos_19_1_test
```

### 2. 의존성 설치

```bash
npm install
```

이 명령어는 다음 패키지들을 설치합니다:
- express: ^4.18.2
- ws: ^8.14.2
- systeminformation: ^5.21.20
- nodemon: ^3.0.1 (개발용)

## 🎮 실행 방법

### 일반 실행

```bash
npm start
```

### 개발 모드 (자동 재시작)

```bash
npm run dev
```

서버가 시작되면 다음과 같은 메시지가 표시됩니다:

```
Server running on http://localhost:3000
System Resource Monitor is ready!
```

## 🌐 사용 방법

1. 브라우저에서 `http://localhost:3000` 접속
2. 실시간으로 업데이트되는 시스템 리소스 확인
3. 우측 상단의 "Export to PDF" 버튼을 클릭하여 현재 상태를 PDF로 저장

## 🔧 환경 설정

### 포트 변경

기본 포트는 3000입니다. 변경하려면:

```bash
PORT=8080 npm start
```

또는 `.env` 파일을 생성:

```
PORT=8080
```

### 업데이트 주기 변경

`server.js`의 다음 부분을 수정:

```javascript
const interval = setInterval(async () => {
    // ...
}, 1000); // 1000ms = 1초 (원하는 값으로 변경)
```

## 📊 모니터링 항목 상세

| 카테고리 | 포함 정보 |
|---------|----------|
| CPU | 제조사, 브랜드, 코어 수, 속도, 온도, 사용률 |
| 메모리 | 전체 용량, 사용량, 여유 공간, 사용률, 스왑 메모리 |
| 디스크 | 파일시스템별 용량, 사용량, 여유 공간, 마운트 포인트 |
| 네트워크 | 인터페이스별 업로드/다운로드 속도 (KB/s) |

| 배터리 | 충전 여부, 잔량, 예상 남은 시간 |
| 시스템 | 플랫폼, 배포판, 커널, 아키텍처, 가동 시간 |

## 🐛 트러블슈팅

### 연결이 안 됨

1. 서버가 실행 중인지 확인
2. 방화벽이 3000 포트를 차단하지 않는지 확인
3. 브라우저 콘솔에서 에러 확인

### GPU 정보가 표시되지 않음

- GPU 정보는 시스템에 따라 제한적으로 지원됩니다
- Linux: `lm-sensors` 설치 필요
- Windows: 대부분 자동 지원
- macOS: 제한적 지원

### PDF 생성이 안 됨

1. 최신 브라우저 사용 (Chrome, Firefox, Edge)
2. JavaScript가 활성화되어 있는지 확인
3. 팝업 차단이 해제되어 있는지 확인
